# 📥 Как поменять/добавить выдаваемый файл (лид-магнит)

Бот отдаёт PDF-гайд. Заменить его можно двумя способами.

---

## Способ A — быстрый (через file_id, рекомендуется для Render)

«file_id» — это код файла внутри Telegram. Отправил файл один раз — получил код —
дальше бот шлёт файл по коду мгновенно.

1. Положи новый PDF в папку проекта (например `lead_magnet.pdf`, заменив старый).
2. Попроси ИИ-помощника: «загрузи новый PDF в Telegram и дай мне новый file_id».
   (Он отправит файл боту в канал и удалит пост, вернёт длинную строку — это file_id.)
3. Зайди на Render → сервис `tgbot-strelyaev` → **Environment**.
4. Найди `LEAD_MAGNET_FILE_ID` → вставь новый file_id → **Save, rebuild and deploy**.

Готово. Текст-подпись к файлу меняется в `app.py` → переменная `LEAD_MAGNET_CAPTION`.

---

## Способ B — простой (через файл в проекте, для VPS)

1. Положи новый PDF в папку проекта.
2. Назови его `lead_magnet.pdf` (или поменяй `LEAD_MAGNET_PATH` в `app.py`).
3. Сделай `git add`, `git commit`, `git push` — Render пересоберётся.
   (Если `LEAD_MAGNET_FILE_ID` пустой, бот возьмёт файл с диска по пути.)

⚠️ Репозиторий публичный: файл, закоммиченный в git, смогут скачать с GitHub.
Если это важно — сделай репозиторий приватным (GitHub → Settings → Danger Zone → Change visibility).

---

## Поменять текст-подпись к файлу

В `app.py` найди `LEAD_MAGNET_CAPTION = (...)` и поменяй текст.
Затем `git commit` + `git push`.
