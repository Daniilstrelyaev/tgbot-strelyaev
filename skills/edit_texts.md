# ✍️ Где менять тексты сообщений

Все тексты лежат в начале файла `app.py` — большими буквами, легко найти.

| Переменная | Что это за сообщение |
|---|---|
| `WELCOME_TEXT` | приветствие после `/start` (под фото) |
| `LEAD_MAGNET_CAPTION` | подпись к PDF-гайду |
| `NOT_SUBSCRIBED_TEXT` | «Я не вижу подписки…» |
| `MENU_TEXT` | заголовок меню (`/menu`) |
| `REVIEW_INTRO_TEXT` | вступление перед анкетой «разбор» |
| `REVIEW_DONE_TEXT` | финал анкеты («Спасибо! Свяжусь…») |
| `CANCEL_TEXT` | ответ на `/cancel` |
| `REVIEW_QUESTIONS` | список вопросов анкеты (по порядку) |

### Кнопки
Тексты на кнопках — в переменных `WELCOME_KEYBOARD`, `NOT_SUBSCRIBED_KEYBOARD`,
`MENU_KEYBOARD`. Меняй только поле `"text"`. Поле `"callback_data"` и `"url"` НЕ трогай —
от них зависит логика.

---

## Как применить изменения

1. Поменял текст в `app.py`.
2. В терминале в папке проекта:
   ```
   git add app.py
   git commit -m "поменял тексты"
   git push
   ```
3. Render сам пересоберёт бота (~2-3 минуты). Проверь `/start`.

💡 Перенос строки внутри текста — это `\n`. Пустая строка между абзацами — `\n\n`.
