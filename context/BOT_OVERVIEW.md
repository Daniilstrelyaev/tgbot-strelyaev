## Что делает бот

Воронка для Telegram-канала Даниила Стреляева (AI-контент / нейросети).

1. Человек жмёт `/start` → видит фото + приветствие + кнопки.
2. Подписывается на канал → жмёт «✅ Я подписался».
3. Бот проверяет подписку (`getChatMember`) → если подписан, присылает **PDF-гайд**
   «Оплата нейросетей без хаоса».
4. Команда/слово «РАЗБОР» → бот собирает анкету (4 вопроса) → присылает заявку
   админу в личку + пишет в `leads.csv`.

## Команды бота

| Команда | Действие |
|---|---|
| `/start` | приветствие с фото и кнопками |

## Анкета «разбор» (4 вопроса по порядку)

1. Имя
2. Ниша / чем занимаешься
3. Ссылка на профиль
4. Как связаться

Результат: заявка уходит админу в ЛС (если задан `ADMIN_ID`) + строка в `leads.csv`.

## Важные ограничения (Render Free)

- **leads.csv не вечный:** при перезапуске/редеплое файл стирается.
  Надёжный канал заявок — **личка админа** (`ADMIN_ID`). CSV — это бонус.
- **Анкета хранится в памяти:** если бот перезапустится посреди заполнения,
  человек начнёт заново (просто напишет «разбор»).
- **PDF по file_id привязан к токену:** сменишь `BOT_TOKEN` — нужно заново
  загрузить PDF и обновить `LEAD_MAGNET_FILE_ID` (см. `skills/add_lead_magnet.md`).
